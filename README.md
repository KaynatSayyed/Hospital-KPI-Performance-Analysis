**Hospital KPI Performance Analysis**

**Objective**
Analyze 36 months of hospital data to evaluate operational performance and patient safety using key nursing KPIs.

**Dataset**
36 months of hospital KPI data (2020–2024)

**Key Metrics**
Bed Occupancy Rate
Patient Fall Rate
Staff Responsiveness

**Key Insights (Impact)**
Average bed occupancy: 97% vs 80% benchmark
Fall rate: 2.5 vs safe limit of 2.0
Staff responsiveness: 64.45% vs 65% benchmark

**Strong correlations:**
Occupancy → Fall Rate: +0.70
Fall Rate → Responsiveness: –0.79

**Outcome**
Identified operational overload impacting patient safety
Recommended occupancy optimization and staffing adjustments
Built Power BI dashboard for ongoing KPI monitoring

**Tools**
SQL | Excel | Power BI
